配置流程

Wespanl 强调可独立完成的配置流程：购买、复制订阅、下载客户端、导入更新、选节点连接。按下列顺序操作即可，无需额外插件。

  1. 选择并开通套餐

    根据每月流量与同时在线设备数选择基础版、旗舰版或团队版。支付完成后账号立即生效。若长期使用，优先年付以降低单价。

  2. 复制机场订阅链接

    进入用户中心的订阅管理，复制通用订阅地址。该链接用于客户端自动拉取节点，请勿公开分享。丢失时可在官网重新生成。

  3. 下载对应平台客户端

    打开本页「客户端官方下载」一节，按 Windows、macOS、Android 或 iOS 选择推荐加速器。只通过 Wespanl 官网指引的渠道获取安装包。

  4. 导入订阅并更新节点

    在客户端中选择从 URL / 订阅导入，粘贴链接后点击更新。稍后将出现香港、日本、新加坡、美国等节点，规则可按需开启分流。

  5. 选择节点并连接

    浏览选普通优化线路，流媒体选原生解锁节点，游戏选 IPLC 或低延迟专线。连接成功即完成整套配置流程，之后只需定期更新订阅。

导入失败时，先检查订阅是否完整、客户端是否为最新版本，再尝试更换节点。旗舰与团队用户可走优先工单。

常见问题

Wespanl 机场如何购买并获取订阅？

在官网选择基础版、旗舰版或团队版并完成支付后，用户中心会生成专属订阅链接。复制该链接即可在各端客户端导入。年付套餐即时到账，流量与设备额度按套餐说明生效。

支持哪些设备和客户端下载？

支持 Windows、macOS、Android、iOS 及 Linux。常用图形客户端包括 Clash Meta、Shadowrocket、Stash、Hiddify 等。请通过本页官方下载说明获取，再用订阅链接更新节点，避免来路不明的修改版。

三个套餐有什么区别，怎样选择？

基础版适合轻度浏览与 3 台设备；旗舰版提升至 300GB、5 台设备，并开放全节点原生流媒体与 IPLC 游戏优化；团队版面向多设备与高流量，含 VIP 节点与定制路由。个人重度使用优先旗舰版。

能否解锁 Netflix 等流媒体？节点覆盖哪里？

旗舰版与团队版提供原生 IP 解锁常见流媒体。节点覆盖香港、日本、新加坡、美国、台湾等热门地区。观看前请更新订阅并选择标注解锁的线路，普通线路以浏览与下载为主。

流量用尽或多设备不够用怎么办？

可在官网升级套餐或按需叠加流量。基础版 3 台、旗舰版 5 台、团队版 20 台同时在线。家庭或小团队建议直接选择团队版，以免反复切换账号。

连接后速度慢或打不开网站如何处理？

先更新订阅并更换节点，关闭可能冲突的系统代理，确认客户端规则未误伤国内站点。游戏与实时通话优先 IPLC。仍异常时，旗舰与团队用户可提交优先工单由值班处理。
